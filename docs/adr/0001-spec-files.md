# 0001. Spec files

Status: accepted

## Context

Statements come in portions. The project needs a trace from the customer words to a requirement, and a review by diff.

## Decision

The specification is a set of markdown files in `docs/spec/` with a statement journal in `docs/statements.md`.

## Alternatives

One `SPEC.md` file. An external tracker.

## Consequences

Small diffs in git. The project needs discipline with identifiers. No external tracker.
