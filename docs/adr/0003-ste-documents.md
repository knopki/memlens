# 0003. STE documents

Status: accepted

## Context

The customer selected STE for the entire project. STE gives short sentences and one meaning for each word.

## Decision

All documents and code comments use ASD-STE100 Simplified Technical English. The README also has the eight languages of the DSH set.

## Alternatives

Russian documents. Plain English.

## Consequences

Clear text for readers with a different first language. The writing needs a check against the STE limits.
