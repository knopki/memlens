# Archive

This folder holds the retired requirement lists. The behavior features in
[docs/features](../../features/README.md) own the live cross-module behavior. Module contracts own
the local rules.

| File                | Content                                       | Retired   |

## Where the retired requirements went

- Behavior rows became scenarios in docs/features. Each feature header cites its REQ ids, its
  proving tests, and its decisions.
- Structure rows moved to the package manifests, to the Boundaries section of AGENTS.md, and to the
  LikeC4 model in docs/arch.
- Document rules live in the Language rules section of AGENTS.md.
