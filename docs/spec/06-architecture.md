# Архитектура

Не начат: ждёт ответа на Q-001 (класс продукта).

## Когда начнётся

Появится первое утверждение о структуре (компоненты, интерфейсы, хранилище) — тогда здесь
появятся: границы системы, внешние интерфейсы, модель данных, схема потоков, нефункциональные
бюджеты (латентность, объём, стоимость) и список того, что осознанно отложено.
