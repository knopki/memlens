Тип: `FR` — функциональное, `NFR` — качество/ограничение поведения, `C` — внешнее ограничение.

Статус: `draft` — как понято, не подтверждено; `accepted` — согласовано, подлежит проверке;

## Заметки по формулировкам

- Одно требование — одно предложение без «и» между независимыми свойствами.
- Механизм реализации сюда не пишется, только наблюдаемое поведение, если он не зафиксирован
  как ограничение (тогда это `C`).
