# Behavior features

Status: pilot. This folder holds the behavior scenarios after the customer
accepts the architecture model. One feature file covers one capability across
modules. Module invariants stay in the code contracts. See
[ADR-0024](../adr/0024-likec4-model.md).

The sample [compaction.feature](compaction.feature) shows the format. Each
scenario names the tests that prove it. The customer has not chosen between
documentation scenarios and executable steps.
