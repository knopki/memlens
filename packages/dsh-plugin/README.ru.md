# @memlens/dsh-plugin

Плагин memlens для DeepSeek Harness.

**Статус:** этапы 1–4. Плагин открывает хранилище памяти, даёт каждому агенту его контекст памяти,
его инструменты памяти и напоминание и запускает фоновое сжатие. Консоль плагина остаётся вне
этого пакета.

## Поверхность памяти

Плагин регистрирует один контекст выполнения для каждого агента. Контекст держит срез памяти и
остаётся стабильным между принятыми триггерами: новая сессия, успешное сжатие harness и простой
выше TTL модели.

Плагин регистрирует эти инструменты в контексте каждого агента:

| Инструмент    | Основной агент | Дочерний (предложение) | Дочерний (чтение) |
| ------------- | -------------- | ---------------------- | ----------------- |
| memory_note   | да             | да, предложение        | нет               |
| memory_find   | да             | да                     | да                |
| memory_open   | да             | да                     | да                |
| memory_map    | да             | да                     | да                |
| memory_forget | да             | нет                    | нет               |
| memory_review | да             | нет                    | нет               |

Дочерний агент с `off` не получает ни инструмента памяти, ни контекста памяти. Предложение
дочернего агента собирается под id его сессии, и родитель получает одну строку отчёта на каждое
предложение, когда дочерний агент завершается.

Напоминание считает вызовы инструментов и ходы основного агента. Достигнутый предел добавляет одну
строку, а запись заметки или напоминание сбрасывает оба счётчика.

Фоновый работник запускает сжатие на пороге загрязнения и на пределе простоя хранилища. Работник
вызывает настроенный маршрут LLM и соблюдает свои лимиты вызовов.

## Точки входа

- Точка входа хоста `@memlens/dsh-plugin` имеет имя плагина `dsh-memlens`. Патч бандла вставляет
  строку `memlens`.
- Точка входа пресета `@memlens/dsh-plugin/preset` имеет имя плагина `memlens/preset`. Пресет
  агента загружает её с ключом `profile`.

### Строка хоста

```yaml
- insert:
    - id: memlens
      name: "@memlens/dsh-plugin"
```

### Строка пресета

Добавь эту строку в список `plugins` пресета агента. Ключ `profile` необязателен. Без ключа действует
профиль `default`.

```yaml
- id: memlens/preset
  name: "@memlens/dsh-plugin/preset"
  config:
    profile: default
```

## Конфигурация

Плагин читает базовый файл `$XDG_CONFIG_HOME/memlens/config.toml`. Плагин не пишет этот файл. Если
файл отсутствует, действует встроенная замена: профиль `default`, scopes `*`, бюджеты 20 и 10 и
scope `user:notes`.

Путь хранилища берётся сначала из конфигурации плагина, затем из `MEMLENS_STORE`, затем из
базового файла.

Настройки объединяются в этом порядке: пресет, патч плагина, базовый профиль. Ключ пресета
`profile` выбирает имя профиля.

Метаданные показа лежат в `locale/<language>.json`. Значок — `icon.svg`.
