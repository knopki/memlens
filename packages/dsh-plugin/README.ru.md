# @memlens/dsh-plugin

[English](README.md) | [中文](README.zh.md) | [Deutsch](README.de.md) | [Español](README.es.md) | [Français](README.fr.md) | [日本語](README.ja.md) | [Português](README.pt.md) | Русский

memlens — долговременная память агента. Заметки лежат в одном хранилище SQLite, а над ними стоит
дерево сводок. Этот пакет даёт эту память агентам DeepSeek Harness. Проблема, устройство, CLI и
консоль описаны в [основном README](https://github.com/knopki/memlens/blob/HEAD/README.md).

## Сводка

`@memlens/dsh-plugin` даёт каждому агенту DeepSeek Harness память memlens. Точка входа хоста
открывает одно общее хранилище. Она даёт каждому живому агенту контекст памяти, инструменты памяти
и напоминание. Она же запускает фонового работника, который сводит старые заметки в строки сводок.
Точка входа пресета позволяет пресету агента выбрать свой профиль памяти. Пакет монтирует консоль
в веб-страницу harness: боковую панель и вкладку сессии.

<a id="use-this-package"></a>
## Использование пакета

### Установка

Добавь пакет в профиль, который используешь:

```sh
dsh plugin --profile web add @memlens/dsh-plugin
```

Флаг `--profile` задаёт имя профиля, например `web` или `desktop`. Остальные аргументы команда
передаёт в pnpm в каталоге профиля.

Точка входа хоста требует сервис LLM, потому что работник отправляет через него вызовы уплотнения.
Сервис workspace точка входа хоста объявляет необязательным.

### Точки входа

- Точка входа хоста — модуль `@memlens/dsh-plugin`. Патч бандла вставляет строку `memlens`, и
  профиль переопределяет именно этот id строки.
- Точка входа пресета — модуль `@memlens/dsh-plugin/preset`. Пресет агента монтирует её как строку
  `memlens/preset`.

Точка входа хоста объявляет имя `memlens`, а точка входа пресета — `memlens/preset`.

#### Строка хоста

```yaml
- insert:
    - id: memlens
      name: "@memlens/dsh-plugin"
```

#### Строка пресета

```yaml
- id: memlens/preset
  name: "@memlens/dsh-plugin/preset"
```

Отсутствующий ключ `profile` выбирает профиль `default`.

### Настройка

Таблица `config` строки хранит настройки её слоя. Пример строки хоста:

```yaml
- insert:
    - id: memlens
      name: "@memlens/dsh-plugin"
      config:
        defaultProfile: work
        budget:
          here: 40
        compaction:
          provider: deepseek-official
          model: deepseek-flash
```

Пример строки пресета:

```yaml
- id: memlens/preset
  name: "@memlens/dsh-plugin/preset"
  config:
    profile: work
    budget:
      here: 30
```

Каждый ключ необязателен. Отклонённое значение даёт пустой слой, поэтому плохая строка не меняет ни
одну сессию.

Пресет переопределяет патч плагина. Патч плагина переопределяет базовый профиль. Ключ пресета
`profile` выбирает имя профиля. Пресет не принимает ни ключ уплотнения, ни ключ хранилища.

Базовый файл — `config.toml` в каталоге конфигурации платформы. Если файла нет, действует встроенная замена:
профиль `default`, области `*`, бюджеты 20 и 10 и область `project:misc`. Отсутствующий раздел файла
даёт значение по умолчанию. Битый или нечитаемый базовый файл оставляет хранилище закрытым, а сессия
продолжается.

Путь хранилища берётся сначала из `store.path` патча, затем из `MEMLENS_STORE`, затем из базового
файла.

Фоновому уплотнению нужен маршрут модели, и плагин никогда не выбирает модель сам. Ключи `provider` и
`model` из примера задают этот маршрут. Идентификаторы берутся из маршрута LLM твоего harness.
Отсутствие провайдера или модели останавливает каждый проход с ошибкой
`The compaction model is not configured. Set provider and model.`

Все ключи, значения по умолчанию и полные примеры — в [Конфигурации](../../docs/configuration.md).

### Правила записи

Основной агент пишет заметку в хранилище. Дочерний агент вместо этого пишет предложение. Запись за
пределами областей профиля становится предложением для человека. `forget` за пределами областей
пишет предложение скрытия.

Дочерний агент с `off` не получает ни инструмента памяти, ни контекста памяти. Предложение ребёнка
собирается под id сессии ребёнка. Родитель получает одну строку отчёта на каждое предложение, когда
ребёнок завершается.

Только CLI и консоль изменяют, стирают, принимают и отклоняют. Просроченное предложение хранилище
отклоняет без человека.

### Версия

Минимальная принятая версия — DeepSeek Harness `0.2.2-rc.3`. Манифест принимает `>=0.2.2-rc.3 <0.3.0-0`.

## Как устроена реализация

<details>
<summary>Внутреннее устройство — нажми, чтобы раскрыть</summary>

Этот раздел объясняет, как плагин держит хранилище и поверхность каждого агента. Наблюдаемое
поведение — в разделе [Использование пакета](#use-this-package).

### Устройство

Хранилище — одна база SQLite с заметками всех сессий. Контекст памяти, инструменты памяти и
напоминание используют хранилище. Этот раздел называет набор этих частей поверхностью агента.
Смонтировать поверхность значит зарегистрировать эти части в контексте одного агента.

- **Одно хранилище на хост.** Хост открывает хранилище один раз и делится им с каждым агентом.
  Точка входа пресета добавляет настройки одному пресету агента и не поднимает второе хранилище.
- **Открытие может не удаться.** Открыть хранилище значит прочитать конфигурацию и подключиться к
  базе. Отсутствующий каталог, блокировка базы другим процессом или битый файл конфигурации
  останавливают открытие. Плагин сохраняет каждую сессию, монтирует поверхность с ошибками и
  повторяет открытие после паузы. Каждая новая попытка ждёт дольше предыдущей.
- **Поверхность каждого агента.** Хост и агент вместе владеют поверхностью агента, и каждая
  регистрация заканчивается вместе с контекстом агента. Дочерний агент не получает напоминания,
  потому что напоминание просит записи в память.
- **Хранилище не открыто.** Контекст и инструменты отвечают ошибками. Сессия без сохранённого
  раздела контекста не получает текста памяти, и поверхность не получает напоминания. Консоль
  показывает ошибку хранилища.
- **Хранилище открывается позже.** Плагин запускает работника и снова монтирует поверхность каждому
  живому агенту. Сессия, начатая на недоступном хранилище, получает память позже.
- **Повторное монтирование сначала снимает старую поверхность.** Реестры хоста отвергают вторую
  регистрацию одного имени. Неудачное монтирование повторяется с паузой в одну секунду, небольшое
  число раз, поэтому случайный сбой не стоит поверхности. Исчерпанное монтирование пишет потерю в
  лог. Код и отладочный лог называют такое повторное монтирование respawn.
- **Работник запускает проход по триггеру.** Проход начинается, когда грязные диапазоны достигают
  размера пакета. Он же начинается по истечении времени простоя хранилища и через десять секунд
  после старта, если работа ждёт. Работник вызывает настроенный маршрут, соблюдает часовой предел
  вызовов и пишет последние события в журнал.
- **Консоль использует сервис Remote.** Плагин регистрирует пространство имён консоли только тогда,
  когда есть сервис Typert. Вкладка после этого читает и пишет память без HTTP-маршрута плагина.

### Карта исходников

| Файл                     | Роль                                                                            |
| ------------------------ | ------------------------------------------------------------------------------- |
| `src/index.ts`           | Точка входа хоста: хранилище, работник, поверхность каждого агента, монтирование |
| `src/preset.ts`          | Точка входа пресета: регистрация настроек в области                             |
| `src/config.ts`          | Две схемы настроек harness с мягкими листьями                                   |
| `src/service.ts`         | Общее хранилище и настройки каждого пресета агента                              |
| `src/runtime.ts`         | Базовая конфигурация и активная область рабочего каталога                       |
| `src/memory-context.ts`  | Контекст памяти, восстановление из истории, триггер обновления                  |

<a id="model-experience"></a>
## Опыт модели

### Системный промпт

#### Что видит модель

Плагин регистрирует контекст памяти каждому агенту с `required: true` и порядком 220, после
встроенных контекстов выполнения. Harness пишет текст как сообщение контекста выполнения и пишет
новое сообщение только тогда, когда текст изменился.

Текст — один раздел `<memory>` с такими частями:

- `<how-to>` держит текст политики и значение `customPromptAppend`. Ключ `customPrompt` заменяет
  весь шаблон.
- `<directions>` держит по строке на каждую из самых новых областей профиля, в виде
  `[<key>] <age> <summary>`. Области старше бюджета сводятся в один список ключей.
- `<here>` держит фронтир активной области: `#<pos> <date> <body>` для заметки и
  `#<a>-<b> <start>..<end> <summary>` для диапазона.

Текст политики объясняет форму дерева, два инструмента чтения и правила записи. [Контракт
контекста](../../packages/core/src/domain/context.ts) держит текст, а
[Промпты](../../docs/prompts.md) называют его место.

#### Влияние на токены

Фиксированная цена на каждом запросе, который держит контекст памяти. Цена растёт с бюджетами
`here` и `directions` и со значением `customPromptAppend`.

#### Влияние на кэш KV

Текст памяти стоит в контексте выполнения в начале запроса. Он не меняется через ходы сессии и
через записи этой сессии. Этот раздел стабилен по префиксу всю сессию.

Плагин собирает текст заново при новой сессии и при сжатии беседы силами harness. Текст меняется
только тогда, когда меняются заметки, бюджеты или свой промпт.

### Схемы инструментов и результаты

#### Что видит модель

Определения инструментов в области видимости агента: описания, параметры и схемы ответа из
`src/tools`. Набор каждого агента зависит от режима профиля:

| Инструмент      | Основной агент | Дочерний `propose` | Дочерний `read` |
| --------------- | -------------- | ------------------ | --------------- |
| `memory_note`   | да             | да, предложение    | нет             |
| `memory_find`   | да             | да                 | да              |
| `memory_open`   | да             | да                 | да              |
| `memory_map`    | да             | да                 | да              |
| `memory_forget` | да             | нет                | нет             |
| `memory_review` | да             | нет                | нет             |

Дочерний агент с `off` не получает ни инструмента, ни контекста памяти.

Каждый вызов отвечает одним собранным текстом. Таблица даёт текст каждого инструмента:

| Инструмент      | Текст, который читает модель                                                        |
| --------------- | ----------------------------------------------------------------------------------- |
| `memory_note`   | `saved <addr>` или `Proposed to your parent: <body> (proposal <id>)`                 |
| `memory_find`   | По строке на каждое попадание, в виде `<addr>  <date>  <kind>  <body>`, или `No hit.` |
| `memory_open`   | Заметку с её longform, по строке на каждого ребёнка диапазона, или `The range holds no record.` |
| `memory_map`    | По строке на каждую область или по строке на каждый диапазон фронтира                |
| `memory_forget` | `Done. A target outside the profile waits for a human.`                              |
| `memory_review` | По строке на каждую запись к проверке, или `reviewed <count> records, next <date>`   |

#### Влияние на токены

Фиксированная цена схемы плюс один компактный ответ на каждый вызов. Отчёт родителю добавляет по
строке на каждое открытое предложение ребёнка, когда ребёнок завершается.

#### Влияние на кэш KV

Схемы стабильны по префиксу, пока набор инструментов и режим профиля не меняются. Вызов и его ответ
встают после переиспользуемого префикса.

### Строки напоминания

#### Что видит модель

Плагин считает вызовы инструментов и ходы основного агента. Счётчик, достигший предела, вставляет
одну строку с ролью пользователя. Строка держит `{n}`, и счётчик встаёт на его место. Тексты по
умолчанию:

```text
[memory] {n} tool calls since the last record. Anything durable: a decision, a correction, a preference, a failed attempt and its cause?
[memory] {n} turns since the last record. Anything durable: a decision, a correction, a preference, a failed attempt and its cause?
```

Раздел `[nudge]` конфигурации задаёт счётчики и тексты. Предел ноль или меньше выключает свой
счётчик.

#### Влияние на токены

Одна короткая строка на каждый достигнутый предел. Запись заметки или напоминание сбрасывает оба
счётчика, поэтому строки редки.

#### Влияние на кэш KV

Строка встаёт после переиспользуемого префикса, поэтому не сбрасывает ни одну прежнюю запись.

<a id="known-limitations-and-deferred-work"></a>
## Известные ограничения и отложенная работа

Эти пределы определяют, когда пакет плохо подходит или требует осторожности. Это текущие ограничения
пакета, а не список задач.

- **Уплотнению нужен настроенный маршрут.** Проход без провайдера или без модели падает с ошибкой "The
  compaction model is not configured. Set provider and model." Консоль показывает эту ошибку на
  экране обслуживания, а затронутые диапазоны остаются грязными до следующего прохода. Смотри
  [Настройку](#configure-it).
- **У повторного монтирования ограниченное число попыток.** Плагин сначала снимает старую
  поверхность, затем монтирует снова с паузой в одну секунду. Исчерпанное монтирование пишет потерю
  в лог, и агент остаётся без поверхности до следующего триггера.
- **Напоминание считает только основной агент.** Дочерний агент не получает напоминания и не
  получает просьбы записать находку.
- **Консоли нужен сервис Typert.** Пространство имён регистрируется только тогда, когда сервис
  появился. Профиль без веб-шлюза не получает консоли, и плагин не сообщает об ошибке.

Эта заметка — рабочий контекст для сопровождающих. Она явно не авторитетна.

дескрипторы.

```sh
pnpm run build
pnpm run typecheck
pnpm run test
```

Команда `pnpm run verify` в корне репозитория запускает сборку и все проверки.
